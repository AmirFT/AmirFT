## 🚀 What I do

I'm a software engineer at **Studio Nona**, working across the full stack. I care about clean, maintainable architecture and shipping things real people use — I've published apps to the App Store and run them in production.

- 📱 **iOS** — Native apps with Swift, SwiftUI & UIKit (SwiftData, ARKit, Vision)
- ⚙️ **Backend** — Production .NET APIs on Clean Architecture: CQRS with MediatR, dual EF Core DbContexts, Quartz background jobs, MassTransit + RabbitMQ sagas, multi-tenant logistics, and JWT + API Key auth
- 🌐 **Web** — Angular SSR apps with TypeScript
- 🐳 **Infra** — Docker-based deployments, Redis, SQL Server, Azure DevOps CI/CD
